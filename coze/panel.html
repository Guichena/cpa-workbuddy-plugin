扣子 Provider

通过官方登录授权接入扣子账号。授权文件由插件生成并落盘，支持自动续期。
需要管理密钥（management key）才能访问账号数据。从 CPA 主面板嵌入时会自动获取，无需输入。错误密钥请勿连点，避免 IP 封禁。

授权扣子账号

  1. 点击「生成授权脚本」，本页会给出一次性脚本（15 分钟内有效）。
  2. 点击「打开扣子」，在打开的 https://www.coze.cn 按官方页面完成登录（手机号 / 抖音 / 飞书 / 火山任一）。
  3. 在扣子页面按 F12 打开开发者工具 → Console，粘贴脚本并回车。
  4. 页面会跳回本插件并自动完成授权，账号随即出现在下方列表。
