# qoderwork 签到链路失败日志补齐测试

结论：qoderwork 签到链路的三个失败分支（campaigns 上游错误 / HTTP ≥400 / 响应解析失败）与 claim 的四个失败分支已补齐账号级日志，4 个新增用例全绿且哨兵变异可精确失败；影响：生产排障时 `docker logs cli-proxy-api | grep qoderwork` 可直接定位失败账号与原因；范围：`qoderwork/billing.go` 失败分支 + 测试端点注入点；非范围：未改签到业务语义、未改端点、未改面板；变化：签到失败从「零日志」变为「含操作名 + 账号标识 + 失败原因」的日志行；完成标准：cgo-shim build/vet/test 全绿 + 哨兵精确 FAIL；术语说明：哨兵变异指故意破坏被测逻辑以验证测试确有判别力的手法；验证状态：本地真实测试完成，生产验证待发布。

- 对应实施文档：`doc/3-实施/2026-10-17_002500_qoder插件吸收qoder2api-hub设备指纹与签到语义实施总览.md`（`CYCLE-03` 的 `TASK-04`）
