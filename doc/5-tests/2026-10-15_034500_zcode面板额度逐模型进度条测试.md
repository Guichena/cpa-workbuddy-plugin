## 三、改动与断言

### 改动（`zcode/panel.html`）

- `quotaHTML` 由「单条汇总进度条」改为 **按 `entitlements[]` 逐模型渲染独立进度条**：每个模型一条 `.pb-item`，标签显示「剩 X / Y」并按「剩余/授予」着色（≤30% 黄、≤10% 红）；回退通道（无真实用量）模型单独展示「授予 X」+ 半透明满格条。
- CSS：新增 `.pb-item` / `.pb-name` / `.pb-used.warn` / `.pb-used.err`；移除本轮不再使用的 `.pb-primary` / `.pb-segment`；`.pb-meta` 上边距 6px→8px。
- `card()`：移除「过期」行（`a.expires_at`），额度判断以进度条为准。

### 断言（`test/zcode/panel_quota_render_repro.mjs`）

| 用例 | 断言 |
| --- | --- |
| A 逐模型进度条数 | 账号 A（2 个 entitlement 均带用量）渲染 **2 条** `pb-item` |
| A 逐模型剩余/授予 | 含「剩 3.00M / 3.00M」与「剩 0 / 5.00M」 |
| A 耗尽模型转红 | 含 `class="pb-bar err"` |
| B 回退通道进度条数 | 账号 B（无用量）渲染 **1 条** `pb-item`，含「授予 1.00M」且不含「剩 」 |
| 冗余信息移除 | 卡片不含 `>过期<` |
| 汇总口径 | 含「今日授予合计」「今日剩余合计」，合计 9.00M，已获取 2 / 未知 1 |
| 授权站点缺省 | 空选值透传 provider=`bigmodel`（0.1.28 起默认中国区） |
