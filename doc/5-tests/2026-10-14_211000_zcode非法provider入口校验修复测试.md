## 三、新增 / 扩展用例

| 用例 | 断言 |
| --- | --- |
| `TestResolveOAuthProvider` | 空值 / 空白 → `zai`；`BigModel`（含空格）→ `bigmodel`；`zhipu`/`zai-cn`/`cn`/`bigmodel-cn` → 明确错误（含「不支持的 OAuth provider」），**不静默回退** |
| `TestHandleActivateStart_RejectsUnknownProvider` | `provider=zhipu` → HTTP **400** + 明确错误文案，且**未触达上游 mock**（`upstreamHit == false`） |

| `TestProviderFromMetadata`（扩展） | 新增非法值 `zhipu` 断言：本层**原样透传**，不在入口归一化 |

## 四、判别力反证（哨兵变异）

| 变异 | 注入内容 | 结果 |
| --- | --- | --- |
| 哨兵 1 | `resolveOAuthProvider` 中移除 `isValidOAuthProvider` 校验分支，非法值直接 `normalizeProviderFamily` | `TestStartAccountOAuth_RejectsUnknownProvider`、`TestResolveOAuthProvider`（4 断言）、`TestHandleActivateStart_RejectsUnknownProvider` **精确 FAIL**；后者报 `expected 400 for unknown provider, got 500`，证明非法值确实穿透到上游 mock |

恢复后重跑全绿，证明新增断言真实进编译且具备判别力。
