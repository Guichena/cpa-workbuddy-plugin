# Qoder 面板宽度与卡片尺寸对齐 WorkBuddy 测试

结论：`qoderwork` 与 `qoder-ai` 两个面板的容器宽度由 1100px 提升至 1400px，卡片网格最小列宽由 320px 提到 360px，卡片在 1264 视口下由 345px 增大到 395px、在 1600 视口下由 345px 增大到 441px，与 WorkBuddy 面板同视口完全一致；影响：CPA 管理台内嵌时两侧空白由 82px 收窄至 0，账号卡片信息密度与 WorkBuddy 对齐；范围：`qoderwork/panel.html`、`qoder-ai/panel.html` 各 3 处 CSS 声明；非范围：未改业务逻辑、未改接口、未改按钮数量与文案、未改 `panel.go` 内嵌方式；变化：`.wrap` 宽度与内边距、`.grid` 列定义与间距、`.actions` 增加换行兜底；完成标准：两插件 `cgo-shim-build.py` build/vet/test 全绿 + 全视口无横向溢出 + 与 WorkBuddy 同视口卡宽一致；术语说明：`auto-fill` 保留空轨道避免单卡被拉满，`minmax(0,1fr)` 允许卡片在窄容器内收缩；验证状态：本地无头浏览器实测完成，生产面板验证待发布。

## 1. 测试范围与依据

- 用户诉求：参考 WorkBuddy 面板，Qoder 面板两侧空白过多，需加宽并把账号卡片调大
- 基线对照：`workbuddy/panel.html` 的 `.wrap{max-width:1400px;padding:24px 20px}` 与 `.grid{repeat(3,minmax(0,1fr));gap:16px}`
- 改动文件：`qoderwork/panel.html`、`qoder-ai/panel.html`

## 2. 改动明细

| 文件 | 选择器 | 改前 | 改后 |
| --- | --- | --- | --- |
| `qoderwork/panel.html` / `qoder-ai/panel.html` | `.wrap` | `max-width:1100px;padding:24px 16px` | `max-width:1400px;padding:24px 20px` |
| `qoderwork/panel.html` / `qoder-ai/panel.html` | `.grid` | `repeat(auto-fill,minmax(320px,1fr));gap:14px` | `repeat(auto-fill,minmax(360px,1fr));gap:16px` |
| `qoderwork/panel.html` / `qoder-ai/panel.html` | `.actions` | `display:flex;gap:8px` | 追加 `flex-wrap:wrap` |

- `.actions` 的 `flex-wrap` 是窄屏兜底：QoderWork 卡片最多 6 个按钮，容器不足时换行而不是横向溢出。

## 3. 真实执行证据

### 3.1 视口实测（agent-browser + Chromium，注入 6 张模拟卡片）

QoderWork 面板（`.wrap` 计算宽度 / 列数 / 卡片宽度 / 按钮行高 / 溢出）：

| 视口 | wrap | 列数 | 卡片宽 | 按钮行高 | 页面溢出 | 卡片溢出 |
| --- | --- | --- | --- | --- | --- | --- |
| 760 | 760 | 1 | 718 | 37 | 无 | 无 |
| 900 | 900 | 2 | 420 | 80 | 无 | 无 |
| 1050 | 1050 | 2 | 495 | 37 | 无 | 无 |
| 1264 | 1264 | 3 | 395 | 80 | 无 | 无 |
| 1400 | 1400 | 3 | 441 | 37 | 无 | 无 |
| 1600 | 1400 | 3 | 441 | 37 | 无 | 无 |
| 1920 | 1400 | 3 | 441 | 37 | 无 | 无 |

- 改前基线（同视口注入旧样式）：1264 与 1600 下 wrap 均为 1100px、卡片 345px、两侧各留白 82px。
- 对齐验证：WorkBuddy 面板在 1264 视口下卡片宽 395px、三列，与 QoderWork 改后完全一致。
- 中间方案排除记录：固定三列（`repeat(3,minmax(0,1fr))`）在 760 视口下把卡片压到 227px，徽标行撑破卡片（`cardOverflow=true`，页面横向滚动 820px）；WorkBuddy 因徽标更少在同宽度不溢出，QoderWork 徽标最多 5 个，故改用 `auto-fill` + 360px 下限，窄屏自动减列。
- 按钮行高 80px 出现在 900/1264 视口，属无头浏览器字体度量偏宽导致的换行；`flex-wrap` 保证其为正常换行而非横向溢出（`scrollWidth == clientWidth`）。
