### 3.1 默认站点改为中国区

| 位置 | 改动 | 断言 |
| --- | --- | --- |
| `panel.html` 下拉框 | `bigmodel` 置首位 + `selected` | — |

### 3.2 claim 的 plan_id 与设备指纹

| 断言 | 用例 | 内容 |
| --- | --- | --- |
| plan_id 动态解析 | `TestClaimAccountStartPlan_MockSuccess` | preview 返回 `zcode-v3-start-plan-0817` → claim 实际提交该值（**不得**为无后缀值）；同时断言 `X-Device-Mid` 非空 |
| plan_id 回退 | `TestClaimAccountStartPlan_FallbackPlanID` | preview 返回 `code 3001` → 回退 `zcode-v3-start-plan-0817`（**字面量断言**，不用常量自比较） |

### 3.3 面板无感验证

- 新增 `loadAliyunCaptchaSDK()`（幂等加载官方 SDK）、`runTracelessVerification(cfg)`（复刻官方链路，**必须同时传 `element` 与 `button`**）、`claimQuota(authID, btn)`（探明验证码 → 无感验证 → 带参数重调 `/claim`）。
- 卡片「未领取」态按钮由「📖 领取指引」改为「🎁 领取额度」；原指引弹窗降级为兜底路径保留。

## 五、生产实测（预研阶段，见预研文档）

| 实验 | 结果 | 判读 |
| --- | --- | --- |
| 无感验证产出参数 | 真实浏览器多轮 100% 成功 | 可行性成立 |
| 缺 `button` 元素初始化 | `{"success":true,"verifyResult":false,"verifyCode":"F001"}` | 证明 `button` 为必需项 |
| `region=sgp` + `plan_id=zcode-v3-start-plan-0817` + 验证头 | `{"code":1003,"msg":"target already exists"}` HTTP 200 | **captcha 校验通过**，进入业务层 |
| `region=sgp` + `plan_id=zcode-v3-start-plan` | `{"code":1001,"msg":"target not found"}` HTTP 200 | captcha 通过，plan_id 无效（佐证后缀必需） |
| `region=cn` + 任意 plan | `{"code":3007,"msg":"captcha verify failed"}` HTTP 400 | region 不匹配则 captcha 不通过 |
| 缺 `X-Device-Mid` | `{"code":3001,"msg":"parameter error"}` | 证明设备指纹为必需头 |
| 宿主面板资源响应头 | 无任何 `Content-Security-Policy` | 外部 SDK 加载不受 CSP 限制 |
