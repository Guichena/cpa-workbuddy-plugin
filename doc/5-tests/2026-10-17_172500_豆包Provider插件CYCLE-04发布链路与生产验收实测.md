### 3.3 端到端真实调用（未通过）

| 通过标准 | 结果 | 证据 |
| --- | --- | --- |
| ④ 真实调用返回豆包回复 | **未通过（外部阻断）** | 生产 `POST /v1/chat/completions`（`doubao/default`）→ HTTP **500**，`err=上游限流，请稍后重试`；间隔重试 5 次（17:03 / 17:06 / 17:08 / 17:11 / 17:19）结果一致 |

**阻断定性证据（证明非代码缺陷）**：

1. **上游原始帧**：临时探针直接读 SSE，收到
   `STREAM_ERROR {"error_code":710022004,"error_msg":"rate limited","extra":{"decision":"{\"from\":\"shark_admin\",\"type\":\"verify\",\"subtype\":\"semantic_reasoning\"...}"}}`
   ——是上游人机验证挑战（`shark_admin / verify`），不是插件构造的请求错误。
2. **同账号本地复现**：本地 `DOUBAO_LIVE_TEST=1` 跑真实链路，`TestCompletionLiveTextSmoke` / `TestCompletionLiveStreamDeltas` / `TestCompletionLiveReplyNotTruncated` 三个用例返回**同一句**「上游限流」，与生产完全一致 → 不是生产出口 IP 或容器环境问题。
3. **会话本身有效**：同一 Cookie 调判据端点 `passport/account/info/v2/` 返回 `message=success` 且 `sec_user_id` 非空 → 不是凭据失效。
4. **设备标识对照实验**：空设备标识 / `s_v_web_id` / `ttwid` 三组分别发起真实对话，**三组同样被拦**（events 均为 3 帧且含限流帧）→ 与设备标识无关。
5. **历史记录**：该限流形态在 2026-10-17 已实测持续 20+ 分钟未解除（见 CYCLE-02 证据），本次从 14:57 持续至 17:19 仍未解除。

**判定**：TASK-010 通过标准①②③ 达成；④ 因上游账号级风控限流阻断，非插件缺陷，属外部环境阻断。按实施总览「阻断条件」登记，待限流解除后复验。

### 3.4 顺带发现的实现缺口（未在本轮修复）

生产导入路径 `saveCredentials`（`doubao/authfile.go:323`）构造 `StoredAuth` 时**未写入 `DeviceID` / `WebID` / `WebTabID`**，三个字段在落盘文件中不存在（只读检查：`key_device_id=0 / key_web_id=0 / key_web_tab_id=0`）。测试路径（`completion_live_test.go`、`completion_test.go`、`failover_test.go`）均显式赋值，故单元测试未暴露。

- 影响：业务 query 中 `device_id` / `web_id` / `tea_uuid` 为空串；本次对照实验显示空值与真实值均被同一风控拦截，**当前不是本次阻断的诱因**。
- 但与需求 §GAP-004「`device_id` / `web_id` / `tea_uuid` 是设备级标识，需与凭据一同持久化」及「每账号独立设备标识」策略不符，属真实缺口，应单独立项修复（不在 TASK-010「纯验证任务」范围内）。
