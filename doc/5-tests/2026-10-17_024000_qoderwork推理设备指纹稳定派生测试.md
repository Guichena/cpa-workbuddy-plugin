# qoderwork 推理设备指纹稳定派生测试

结论：qoderwork 推理链路的设备标识（`cosy-machineid`/`cosy-machinetoken`/`cosy-machinetype`）由「每次会话随机 UUID」改为「按账号 UID 稳定派生」，同一账号跨 token 刷新与进程重启保持恒定，多账号互相隔离；影响：生产 9 个账号的推理请求在服务端呈现为 9 台稳定且互不相同的虚拟设备，消除每约 4 小时 token 刷新导致的设备标识漂移；范围：`qoderwork/sign.go`；非范围：未改会话密钥（仍随机）、未改上游协议与签名算法、未改 qoder-ai；变化：同账号 `cosy-machineid` 在会话重建前后一致；完成标准：Go 测试全绿 + 双哨兵正交精确 FAIL + 形态兼容；术语说明：设备指纹指上游用于识别「同一台物理设备」的三个 `cosy-machine*` 请求头；验证状态：本地真实测试完成，生产验证待发布。

## 3. 实现要点

| 项 | 实现 |
| --- | --- |
| 种子 | `cosyFingerprintSeed(id)`：UID 优先 → 访问令牌 → `"anonymous"` 占位 |
| MachineID | `uuid.NewSHA1(uuid.NameSpaceOID, "qoderwork:machine:"+seed)` → **保持 UUID 形态** |
| MachineToken | `base64.RawURLEncoding(sha512("qoderwork:machinetoken:"+seed))[:43]` → **保持 43 字符 base64url** |
| MachineType | `hex(sha256("qoderwork:machinetype:"+seed))[:18]` → **保持 18 位十六进制** |
| TempKey / Info | **保持随机**（非设备标识，仅用于加密身份载荷） |

**形态兼容性设计**：三种派生值刻意复刻原随机值的形态（UUID / 43 字符 base64url / 18 位 hex），以对冲「上游对 `cosy-machineid` 有格式校验」的风险（计划 `RISK-01`）。

## 4. 用例与断言

| 用例 | 断言 | 防的是什么 |
| --- | --- | --- |
| `TestDeriveMachineIdentity_StableForSameUID` | 同 UID 两次构造的三项设备标识完全相同，且 TempKey/Info 仍不同 | 指纹漂移；且防「把会话密钥也固定化」的过度修改 |
| `TestDeriveMachineIdentity_IsolatedAcrossAccounts` | 不同 UID 的三项设备标识互不相同 | 多账号被判同设备 |
| `TestDeriveMachineIdentity_ShapeCompatible` | UUID 正则 / 43 字符 / base64url 字符集 / 18 位 hex | 形态变化致上游格式校验拒绝 |
| `TestCosyFingerprintSeed_FallbackChain` | UID 优先、缺 UID 用令牌、皆空返回占位 | 种子缺失致 panic 或串号 |
| `TestDeriveMachineIdentity_TokenChangeKeepsFingerprint` | 同 UID 下令牌变化不影响三项设备标识 | token 刷新（会话重建主因）导致漂移 |

### 5.2 双哨兵正交变异（判别力验证）

**哨兵 1**：`machineID := deriveMachineID(seed)` → `uuid.NewString()`（退回随机）

```

```

**哨兵 2**：派生忽略 seed（`"qoderwork:machine:"+seed` → `"qoderwork:machine:fixed"`）

```
--- FAIL: TestDeriveMachineIdentity_IsolatedAcrossAccounts (0.00s)

```

**正交性证明**：
- 哨兵 1（退回随机）→ 命中「幂等」+「令牌刷新不变」，**不**命中「跨账号隔离」（随机值天然隔离）
- 哨兵 2（忽略 seed）→ 命中「跨账号隔离」，**不**命中「幂等」（恒定值天然幂等）

两个断言的判别方向正交，说明测试不是单一维度的重复覆盖。

## 7. 未覆盖与残余风险

- **生产行为未验证（关键）**：本测试只证「派生逻辑正确」，**不证上游接受新指纹**。发布后必须做单账号真实推理验证（`test-active` 或真实推理），确认鉴权通过（`RISK-01`/`RISK-02`）。
- **上游风控反应不可预测**：从随机指纹变为稳定指纹属上游可见的行为变更，无法本地验证风控反应。依据外部项目经验（`EXT-001`）这是正向变化，但不作保证。
- **qoder-ai 同款缺陷未修**：`qoder-ai/sign.go` 的 `newCosySession` 与 `qoderwork/sign.go` 修改前**逐字节同构**（段落 md5 一致：`33349715c93be5ce1043cb2f841129ed`），存在同一缺陷。本计划 `CYCLE-01` 范围仅含 qoderwork，故未改；已登记为待评估项。
- **`RISK-03` 已在上轮取证中澄清**：签到链路不发机器头（`billing.go` 仅 `Cosy-ClientType`+`UA`），故本改动**不影响签到成功率**，只影响推理链路。
