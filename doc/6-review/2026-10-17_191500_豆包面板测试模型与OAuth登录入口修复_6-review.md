## STYLE-08 语言与框架特异写法

- 覆盖维度：维度2 编写习惯与代码风格（语言与框架层）
- 规则 Owner：`golang-patterns`、`frontend-ui-visual-rules`
- 检查结果（Go）：
  - 常量显式赋值，无 `iota`（`activeTestTimeout`、`testPingText`、`loginStateTTL`）。
  - 无多余 `strings.TrimSpace`：`preview` / `cookie` / `key` 的 TrimSpace 均用于「判空或比较前统一口径」；`authID` 的 TrimSpace 用于匹配。
  - `sync.Mutex` 保护 `loginSessions`，且 `pruneExpiredLoginSessionsLocked` 在注释与命名上标明「调用方须持锁」，避免误用。
  - 无 goroutine 泄漏：`runActiveTest` 的 context 由 `defer cancel()` 收尾，`streamCompletion` 的 `defer resp.Body.Close()` 保证首帧返回后立即关流。
  - map 并发安全：所有 `loginSessions` 读写都在锁内。
- 检查结果（前端）：
  - 颜色全部走 `var(--*)` 令牌，未硬编码色值；弹窗样式复用面板既有 `--card` / `--border` / `--radius-lg` / `--acc`。
  - 弹窗 `.mask` 使用 `position:fixed; inset:0` + `z-index:50`，与面板无既有 z-index 冲突。
  - 事件用委托（`list` 容器 + `closest("button[data-act]")`），与既有按钮事件链一致，未改成逐按钮绑定。
  - 结果区用 `textContent` / `esc()` 输出，无 XSS 注入面。
- 证据：`STYLE-08：doubao/active_ping.go（常量显式赋值、context+defer 关流）、doubao/panel.html（全部走 CSS 令牌、事件委托与既有写法一致）`
